# Вычисление выражений

Общий движок числовых выражений для любых игр, включая новеллы без RPG. Его используют диалоги, схемы и формулы характеристик.

```scenario
set money=rnd(3,5)
cset total "1+2+${money}"
ptext "Найдено ${money} монет."
action item.add id=money/coin count=${money}
```

`rnd(3,5)` один раз выбирает целое число от 3 до 5 включительно. Текст и действие читают сохранённое значение. Действие инвентаря требует модуля предметов и определения монеты; вычисления и текст работают без RPG. В локализованной строке используйте такой же шаблон `${money}`.

`set имя значение` сохраняет строку как раньше. `set имя=выражение`, `cset имя выражение` и `cset имя=выражение` вычисляют число. Выражение с пробелами заключайте в кавычки. Переменные принадлежат текущему диалогу; для постоянного состояния служат сюжетные флаги.

Поддерживаются арифметика `+ - * / % ^`, скобки, сравнения, `! && ||`, тернарное выражение, функции `min`, `max`, `abs`, `floor`, `ceil`, `round`, `sqrt`, `clamp`, `if`, `rnd`, `rand`, `chance`. `${Имя}` сохраняет регистр. Десятичный разделитель — точка. `rnd` требует упорядоченные целочисленные границы Int32. `rand` сохраняет прежнее поведение формул характеристик.

Неизвестная или нечисловая переменная, деление на ноль и неконечный результат останавливают диалог с указанием источника и строки, до следующих наград. Проверка синтаксиса не расходует случайные числа. Старые формулы характеристик сохраняют прежний мягкий режим.

Авторы модов подключают функции через `IExpressionFunctionStrategy`, операторы через `IExpressionBinaryStrategy` и `IExpressionUnaryStrategy`. Публичные стратегии автоматически обнаруживаются при загрузке мода и удаляются при выгрузке; кеши разбора сбрасываются. DSL-команды также остаются стратегиями. Полный пример функции и приоритеты операторов — в [английском руководстве](en.md).
